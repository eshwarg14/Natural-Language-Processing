# 🌍 Text Language Identifier

A simple GUI-based application that detects the language of a given text using Python and the langdetect library. Built with Tkinter, this tool helps identify languages along with confidence scores.

## ✨ Features

- 🌍 Detects language from input text  
- 🧠 Supports multiple languages (50+ languages)  
- 📊 Displays language name, code, and confidence  
- 🖥️ Simple and clean GUI using Tkinter  
- ⚡ Fast and lightweight  

---

## 🧠 What is Language Detection?

Language detection is the process of identifying the language of a given text.

👉 Example:
- "Hello, how are you?" → English
- "ನಮಸ್ಕಾರ, ಹೇಗಿದ್ದೀರಿ?" → Kannada
- "नमस्ते" → Hindi  
- "Hola amigo" → Spanish  

---

## 🤖 What is langdetect?

The **langdetect** library is a Python package used to detect the language of text.

- 🌐 Supports many languages  
- 🧠 Uses statistical models  
- 📊 Provides probability/confidence score  
- ⚡ Works offline (no API needed)

## 🛠️ How It Works

- 📝 User enters text in input box  
- 🤖 langdetect analyzes text patterns  
- 🌍 Detects language code (e.g., en, hi, fr)  
- 📖 Maps code to full language name  
- 📊 Displays confidence score
