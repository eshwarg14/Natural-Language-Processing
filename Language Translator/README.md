# 🌍 AI Language Translator

A web-based AI language translator built using Python and Streamlit. This application allows users to translate text between multiple languages with real-time feedback, metrics, and translation history.

---

## Preview

![Demo](https://github.com/eshwarg14/Natural-Language-Processing/raw/0baa99ebfb9e3f61b9add4c331a727e0860f67ff/Images/TRS.png)

---

## ✨ Features

- 🌍 Translate text between multiple languages  
- 🧠 Supports 20+ languages  
- ⚡ Real-time translation  
- 📊 Word & character count  
- 📈 Translation metrics (confidence, speed, quality)  
- 📚 Translation history tracking  
- 🖥️ Interactive UI using Streamlit  

---

## 🧠 What is Language Translation?

Language translation is the process of converting text from one language to another while preserving meaning.

👉 Example:
- "Hello" → "Hola" (Spanish)  
- "नमस्ते" → "Hello" (English)  

---

## 🤖 How It Works

- 📝 User inputs text  
- 🌐 Select source and target language  
- 🤖 Translator processes text using API  
- 📊 Displays translated output  
- 📚 Saves history for future reference
