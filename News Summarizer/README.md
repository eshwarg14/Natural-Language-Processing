# 📰 AI News Summarizer

A GUI-based AI application that summarizes news articles from a URL or pasted text into clear bullet points. Built using Python, Tkinter, and OpenRouter API.

## ✨ Features

- 🌐 Summarize articles from URL  
- 📝 Paste and summarize custom text  
- 🤖 AI-powered summarization  
- 📊 Clean bullet-point output  
- 🖥️ Simple GUI using Tkinter  
- ⚡ Fast processing with threading  

---

## 🧠 What is Text Summarization?

Text summarization is a process of converting long text into a shorter version while keeping important information.

👉 Example:
- Long news article → Short bullet points

## 🔑 API Setup

1. 🌐 Go to: https://openrouter.ai  
2. 🔐 Create account / login  
3. 🔑 Generate API key  
4. Replace in code:

```python
API_KEY = "your-api-key"
```

---


## 🛠️ How It Works

- 🌐 Fetch article from URL using newspaper3k  
- 🧹 Clean and trim text  
- 🤖 Send text to AI model via API  
- 📊 AI generates summary in bullet points  
- 🖥️ Display summary in GUI
